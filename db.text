A couple of important notes:

- This seeds `auth.users`, so you can log in with those accounts.
- I did not seed `symptoms` and `prescriptions` here, because your app stores those using custom AES-256-GCM application encryption, not plain SQL text. If you insert plaintext there, your UI decryption will fail.
- After running this, sign in as a patient or doctor and create symptoms/prescriptions through the app to generate real encrypted PHI rows.
